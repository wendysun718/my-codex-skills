# Wendy 的 Codex Skills

这是一个面向真实业务操作的个人 Codex Skills 仓库。

仓库中的 Skill 不是只有几句提示词，而是包含了完整的工作流程、判断标准、安全边界、计算脚本和参考资料。目标是让不懂技术的用户也可以用自然语言告诉 Codex 想做什么，再由 Codex 按照明确步骤完成调研、整理和执行。

每个 Skill 都放在 `skills/` 下的独立文件夹中，可以单独安装、修改或分享。

## Skill 列表

### 国内电商提示词

**Skill ID：** `domestic-ecommerce-prompts`

**适用平台：** 豆包、微信朋友圈、微信视频号、国内电商商品素材

**状态：** 可用于生成中文商品图提示词、朋友圈营销文案和带货短视频脚本

这个 Skill 用于把国内微信卖货和国内电商商品展示需求，整理成可直接复制到豆包使用的中文内容。

它重点支持：

- 商品主图提示词
- 商品宣传图提示词
- 商品功能细节图提示词
- 朋友圈营销文案
- 带货短视频脚本

设计原则：

- 输出中文提示词，直接给豆包看
- 不默认生成冗长素材包，只生成用户选择的单个素材类型
- 不输出九宫格规划、群聊话术或私聊话术
- 保留产品图里的颜色、版型、结构、纹理和可见细节
- 不编造销量、价格、库存、认证、材质比例或无法确认的功效
- 朋友圈文案避免土味吆喝，偏内容营销和产品种草

**Skill 文件夹：** [`skills/domestic-ecommerce-prompts`](skills/domestic-ecommerce-prompts)

**详细执行规范：** [`SKILL.md`](skills/domestic-ecommerce-prompts/SKILL.md)

### 妙手 TikTok 选品上架助手

**Skill ID：** `miaoshou-tiktok-operator`

**适用平台：** 妙手 ERP、TikTok Shop

**当前重点市场：** 马来西亚

**状态：** 可用于选品、利润筛选和上架准备；正式发布需人工确认

这个 Skill 用于帮助跨境电商卖家完成从“妙手 ERP 找商品”到“准备 TikTok Shop 商品”的完整流程。

它不是简单地寻找采购价最低的商品，而是同时考虑：

- 商品是否适合马来西亚的天气、生活和户外场景
- 商品是否容易通过短视频展示价值
- 采购、物流、平台费用、达人佣金和退款后是否仍有利润
- 商品图片、品牌、类目和宣传内容是否存在风险
- 商品更适合作为引流款、利润款、组合款还是测试款
- 是否应该先保存为草稿，而不是直接发布

#### 主要能力

1. **妙手 ERP 选品**
   - 在用户已登录的妙手 ERP 网页中搜索候选商品
   - 收集价格、重量、库存、变体、供应商和图片信息
   - 优先筛选轻小、实用、容易演示的商品

2. **马来西亚市场适配**
   - 关注炎热天气、雨季、户外运动、通勤和旅行场景
   - 判断商品是否有清晰的当地使用理由
   - 避免只因为价格便宜就盲目铺货

3. **利润核算**
   - 计算采购、物流、包装、平台费用、达人佣金、优惠券、广告和退款预留
   - 输出预计单件利润、利润率和综合选品评分
   - 自动拦截亏损或利润过低的候选商品

4. **商品资料准备**
   - 准备英文标题、描述、类目、属性、变体、价格和库存
   - 检查中文水印、供应商信息、未授权品牌和不可信宣传
   - 提供适合短视频展示的卖点方向

5. **安全上架**
   - 默认先调研和生成草稿
   - 发布前再次展示店铺、国家、商品、售价、库存和预计利润
   - 只有获得明确确认后才执行正式发布

6. **上架后复盘**
   - 根据浏览、点击、订单和利润判断商品表现
   - 给出保留、优化、组合销售或下架建议

#### 四种工作模式

| 模式 | 用途 | 是否会发布商品 |
|---|---|---|
| 调研模式 | 搜索、比较、计算利润并生成候选清单 | 否 |
| 准备模式 | 生成完整商品资料并保存草稿 | 否 |
| 发布模式 | 发布已经明确批准的商品 | 是，发布前再次确认 |
| 复盘模式 | 分析商品表现并提出优化建议 | 否 |

#### 适合谁使用

- 刚开始运营 TikTok Shop、商品数量较少的卖家
- 使用妙手 ERP 进行采集、认领或刊登的跨境卖家
- 想测试低价引流款，但担心运费和佣金吃掉利润的人
- 希望减少机械选品和商品资料整理工作的人
- 希望保留人工审核，而不是让程序盲目批量上架的人

#### 不适合直接处理

- 仿牌、盗版或未经授权的品牌商品
- 食品、保健品、药品、医疗宣称商品
- 高风险电子产品、电池、儿童安全用品和受监管产品
- 信息不完整、库存不明或物流路线不清晰的商品
- 要求绕过验证码、平台审核或账号安全措施的操作

#### 输出内容

一次标准选品任务通常会输出：

- 候选商品清单
- 商品角色：引流款、利润款、组合款或测试款
- 建议售价
- 完整成本估算
- 预计单件利润和利润率
- 马来西亚适配度
- 风险说明
- 是否推荐上架
- 商品标题、描述和短视频卖点建议

## 安装

### 从 GitHub 安装

仓库上传 GitHub 后，把仓库链接发给 Codex，然后说：

```text
请从这个 GitHub 仓库安装 skills/miaoshou-tiktok-operator：
https://github.com/wendysun718/my-codex-skills
```

Codex 会使用 Skill 安装流程处理。也可以下载仓库 ZIP，再手动安装对应文件夹。

安装国内电商提示词 Skill：

```text
请从这个 GitHub 仓库安装 skills/domestic-ecommerce-prompts：
https://github.com/wendysun718/my-codex-skills
```

### 手动安装

将整个 `skills/miaoshou-tiktok-operator` 文件夹复制到：

```text
~/.codex/skills/miaoshou-tiktok-operator
```

或将整个 `skills/domestic-ecommerce-prompts` 文件夹复制到：

```text
~/.codex/skills/domestic-ecommerce-prompts
```

然后重启 Codex。

## 使用示例

### 生成国内电商商品图提示词

```text
使用 $domestic-ecommerce-prompts，为这款女装防晒衣生成商品宣传图提示词。
目标客户是30-45岁女性，卖点是轻薄、防晒、不闷热、日常通勤好搭。
提示词要给豆包看。
```

### 生成朋友圈营销文案

```text
使用 $domestic-ecommerce-prompts，为这款商品生成朋友圈营销文案。
不要土味吆喝，突出产品特点、适合人群和日常场景。
```

### 只做选品，不上架

```text
使用 $miaoshou-tiktok-operator，从我已经登录的妙手 ERP 中寻找
20款适合马来西亚的户外商品。先计算利润并生成候选名单，不要上架。
```

### 准备商品草稿

```text
使用 $miaoshou-tiktok-operator，把我批准的5款商品整理成
TikTok Shop Malaysia 商品草稿，检查标题、图片、类目、售价和库存，
但不要正式发布。
```

### 复盘已有商品

```text
使用 $miaoshou-tiktok-operator，检查店铺已有商品的浏览量、点击和订单，
告诉我哪些商品应该继续保留、优化、做组合销售或停止测试。
```

## 安全说明

- 仓库中不得保存账号、密码、验证码、Cookie、访问令牌或真实店铺 ID。
- 正式上传前，应再次搜索个人路径、邮箱、手机号、店铺名称和访问凭证。
- 使用者应通过自己已经登录的网页会话完成操作。
- 商品正式发布前应核对目标店铺、售价、库存、利润和商品合规性。
- 本 Skill 不使用妙手 ERP 的非公开接口，不保证第三方网页改版后仍能完全自动操作。

## 重要限制

- 利润结果依赖输入的成本和费率，默认值只能作为初步估算。
- TikTok Shop 和妙手 ERP 的页面、类目、费用及规则可能发生变化。
- 使用者需要对商品合规、商标授权、税务和最终发布决定负责。
- 本 Skill 是运营辅助工具，不构成法律、税务或平台合规意见。
