## 商品主图

```text
【[product]｜商品主图提示词】

请根据我上传的产品平面图，生成一张适合国内电商和微信朋友圈使用的高质感商品主图。

画面要求：
1. 商品必须是第一视觉重点，主体清楚、轮廓完整、细节清晰。
2. 背景干净，可以使用暖白、浅灰或高级棚拍背景。
3. 光线柔和，有真实阴影和商品质感，不要廉价广告感。
4. 整体像国内头部电商的商品展示图，干净、高级、可信。
5. 建议比例 4:5。

产品：[product]
目标客户：[customer]
核心卖点：[selling_points]
画面风格：[style]
限制：必须严格保留上传产品图里的颜色、版型、长度、纹理、结构、图案、可见细节和商品轮廓。不要改款，不要新增不存在的口袋、纽扣、拉链、图案、吊牌、logo、文字、水印或包装。
```

## 商品宣传图

```text
【[product]｜商品宣传图提示词】

请根据我上传的产品图，生成一张适合朋友圈和视频号封面使用的商品宣传图。

画面要求：
1. 把商品放在更有吸引力的生活方式场景里，但不要抢走商品主体。
2. 画面要突出 [selling_points]，让客户一眼知道这款产品适合什么场景、解决什么需求。
3. 适合 [customer]，氛围自然、有质感，不要夸张网红风。
4. 不要添加价格、折扣、销量、虚假 logo、宣传字或品牌包装。
5. 建议比例 4:5 或 9:16。
```

## 商品功能细节图

```text
【[product]｜商品功能细节图提示词】

请根据我上传的产品图，生成一张商品功能细节图。

画面要求：
1. 只展示原图中真实可见的结构和细节。
2. 重点表现：[selling_points]。
3. 画面像高端商品详情页的细节图，光线柔和，质感清楚，布局干净。
4. 不要编造原图里没有的功能、材质、认证、实验效果或文字标签。
5. 建议比例 1:1 或 4:5。
```
