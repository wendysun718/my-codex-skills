# Job Application Tracker

## 中文

Job Application Tracker 是一款帮助求职者自动整理申请信息的 AI Skill。用户可以批量提供职位链接、JD、截图、确认邮件或零散备注，由 GPT 或其他支持 Skill 的 Agent 整理到 Notion。首次使用时，它会创建中文或英文版的 10 列追踪表，并加入示例；每个岗位的详情页会逐条保留 JD 中的全部要求，区分必备条件与加分项，同时分别记录 CPT、OPT 和签证担保限制。后续还可根据新信息更新申请状态和下一步行动，减少手动录入与维护的负担。

## English

Job Application Tracker is an AI skill that helps job seekers organize application information with less manual data entry. Users can provide batches of job links, descriptions, screenshots, confirmation emails, or notes, and a compatible AI agent organizes them in Notion. On first use, it creates a 10-column tracker in Chinese or English with an example entry. Each job page preserves every requirement stated in the JD, separates required and preferred qualifications, and records CPT, OPT, and visa sponsorship conditions without guessing when information is missing. As new information arrives, the skill can update application stages and next actions, keeping the tracker useful throughout the job search.
